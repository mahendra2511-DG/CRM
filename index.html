Why this project exists

Problem Statement

Axon, a growing retail and consumer product company, relies on CRM data to drive marketing campaigns, loyalty programs and post-sale service decisions — but the current setup is fragmented, has no real-time insight, and gives limited visibility into customer behaviour and sales performance.

Tools used in this capstone

One CRM export, four tools, one story

Each tool plays a distinct role in the pipeline — interviewers frequently probe why a given phase used the tool it did.

How the data moves through Snowflake to both BI tools

Excel: profile the 5 raw Salesforce exports, document data-quality issues, and build a first-pass pivot dashboard directly from the spreadsheet.
Snowflake: load Raw tables via COPY INTO, clean and type into Staging (dim_account, dim_user, fact_lead, fact_opportunity), then build the two Mart views — vw_lead_funnel and vw_opp_summary.
Tableau & Power BI: both connect live to the Mart views via JDBC/ODBC — never to the raw CSV/XLSX files, and never to each other.
QA: run SQL directly against the Mart views and reconcile every KPI against both dashboards within ±0.1%.

Data Pipeline

Salesforce CRM → ETL/ELT → Snowflake → Power BI / Tableau

The full path data actually travels: exported from Salesforce as flat files, cleaned and loaded into a layered Snowflake warehouse, and consumed live by both BI tools — nothing connects directly to the raw export.
